# Full19

19産業すべてでStakeholder 5 × Context 6を全直積し、570候補を生成する基準方式です。

## Gemの作成

1. `instructions.md` の本文をGemの「指示」へ貼り付ける。
2. `knowledge/` 内の6ファイルをすべてKnowledgeへ追加する。
3. 特許CSV、特許PDF、またはCapability Cardは、会話開始時に入力する。

## 実行

`特許入力 → 発散前確認票 → 承認 → Run Manifest → 開始 → 1産業30件 → 次へ`

候補は19batch、合計570件です。near / adjacent / farは説明用であり、産業やtupleの削除には使いません。
