# GemC テスト用入力

## 複数行の特許CSVから選ぶ

```text
添付CSVから、公報番号と発明名称だけを表で表示してください。
対象を指定するまで、特許分析、産業分類、候補発散は開始しないでください。
```

対象指定後：

```text
対象: JPxxxxxxxxxx
この1行だけを読み込み、発散前確認まで進めてください。
候補発散はまだ開始しないでください。
```

## 公報番号を最初から指定する

```text
添付CSVの公報番号JPxxxxxxxxxxを対象に、要求機能②を開始してください。
対象行だけを読み込み、発散前確認までを表で示してください。
この時点では候補発散を開始しないでください。
```

## PDFまたは要求機能①の分析結果を入力する

```text
添付した特許を対象に要求機能②を開始してください。
まず特許を理解し、19産業すべてを含む発散前確認まで進めてください。
この時点では候補発散を開始しないでください。
```

## 探索計画を修正する

```text
修正:
- 産業B「漁業」は遠隔ではなく隣接としてください。理由は〇〇です。
- 産業E「製造業」は近接としてください。
影響を受ける行と候補総数だけを更新してください。まだ発散は開始しないでください。
```

## 発散を開始する

```text
承認
```

実行計画の確認後：

```text
開始
```

## 項目の説明を再表示する

```text
項目説明
```

## 要求機能③用データを出力する

```text
要求機能③用データ
```

## 主な確認点

- 通常表示の見出し、根拠区分、距離区分が日本語である。
- 内部の数式、変数、割当番号、英語列名が通常表示に出ない。
- 産業表が「主体×文脈の組み合わせ範囲」を具体的に説明する。
- 候補一覧が7列の日本語表で、意味的価値を中心に読める。
- 「主体×文脈」に実際の区分名が表示される。
- 産業名や内部IDを候補行ごとに繰り返さない。
- 候補数が近接6件、隣接12件、遠隔30件になっている。
- 英語17列は`要求機能③用データ`を指示した場合だけ表示される。
