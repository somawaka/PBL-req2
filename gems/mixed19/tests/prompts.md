# GemC テスト用入力

## 複数行の特許CSVから選ぶ場合

```text
添付CSVから、公報番号と発明の名称だけを表形式で表示してください。
私が対象を指定するまで、特許分析、距離分類、候補発散は開始しないでください。
```

対象指定後：

```text
対象: JPxxxxxxxxxx
この1行だけを読み込み、GemCの発散前確認票まで進めてください。
候補発散はまだ開始しないでください。
```

## 公報番号を最初から指定する場合

```text
添付CSVの公報番号JPxxxxxxxxxxを対象に、要求機能②を開始してください。
対象行だけを読み込み、特許を分析し、GemCの発散前確認票までを表形式で提示してください。
この時点では候補発散を開始しないでください。
```

## PDFまたは要求機能①の分析結果を入力する場合

```text
添付した特許を対象に要求機能②を開始してください。
まず特許を分析し、GemCの発散前確認票までを提示してください。
19産業を一つも削除せず、近接6件、隣接12件、遠隔30件の探索量を表示してください。
この時点では候補発散を開始しないでください。
```

## 修正例

```text
修正:
- 産業B「漁業」は遠隔ではなく隣接としてください。理由は〇〇です。
- 産業E「製造業」は近接としてください。
影響を受ける表と候補総数だけを更新してください。まだ発散は開始しないでください。
```

## 発散開始

```text
承認
```

実行計画の確認後：

```text
開始
```

確認項目：

- 発散前確認票の見出し・根拠区分・距離区分が日本語である。
- 特許理解表が5項目に整理されている。
- ステークホルダー確認表に重複名称や関係仮説がない。
- 産業表にrotation等の内部語が表示されない。
- 候補一覧が箇条書きではなくMarkdown表である。
- 各産業の候補が近接6件、隣接12件、遠隔30件になっている。
