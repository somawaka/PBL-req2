# Mixed19

19産業を一つも削除せず、既存用途からの距離に応じて各産業内の探索量を変える方式です。

## Gemの作成

1. `instructions.md` の本文をGemの「指示」へ貼り付ける。
2. `knowledge/` 内の7ファイルをすべてKnowledgeへ追加する。
3. `tests/prompts.md` と `tests/checklist.csv` を使ってPreviewを確認する。
4. 特許CSV、特許PDF、または要求機能①の分析結果は、会話開始時に入力する。

## 実行

`特許入力 → 特許理解と19産業の探索計画 → 人間確認 → 承認 → 実行計画固定 → 開始 → 1産業ずつ生成 → 次へ`

探索量は次のとおりです。

- 近接産業：6候補
- 隣接産業：12候補
- 遠隔産業：30候補（5主体×6文脈の全組合せ）

遠隔は低評価という意味ではありません。既存用途から遠い産業ほど、意外な意味的価値を逃さないよう深く探索します。

## 確認表の保持について

発散前確認表は、同じGem会話内では後続の距離分類・実行計画・候補生成の前提として参照されます。ただし、Gem外のデータベースやファイルへ永続保存されるわけではありません。

承認後は、19産業の距離と生成数を「実行計画」として会話内で固定します。全結果の保存、別会話からの再開、欠落検査、CSV結合には、将来のAPIバックエンドが必要です。

各産業の候補一覧はMarkdown表で出力します。
