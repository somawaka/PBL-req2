# Mixed19

19産業を残したまま、既存用途からの距離に応じて「主体×文脈」の組み合わせ数を変える発散方式です。

| 産業の距離 | 1産業の生成数 | 組み合わせ方 |
|---|---:|---|
| 近接 | 6件 | 5主体と6文脈を各1回以上扱う |
| 隣接 | 12件 | 主体と文脈の対応を変えた2通りを扱う |
| 遠隔 | 30件 | 5主体×6文脈の全組み合わせを扱う |

遠隔は低評価という意味ではありません。既存用途から遠い産業ほど、意外な意味的価値を逃さないため深く探索します。

## Gemの作成

1. `instructions.md`をGemの「指示」へ貼り付ける。
2. `knowledge/`内の7ファイルをすべてKnowledgeへ追加する。
3. `tests/prompts.md`と`tests/checklist.csv`でPreviewを確認する。
4. 会話開始時に、特許CSV、特許PDF、または要求機能①の分析結果を入力する。

## 会話の流れ

`特許入力 → 特許理解と探索計画 → 人間確認 → 承認 → 開始 → 1産業ずつ発散 → 次へ`

Gemの通常表示は、人が内容を理解・確認するための日本語表です。内部の数式、割当番号、英語のデータ列名は表示しません。

要求機能③へ渡すデータが必要な場合は、同じ会話で`要求機能③用データ`と入力します。永続保存、別会話からの再開、全19産業の自動実行にはAPIバックエンドが必要です。
