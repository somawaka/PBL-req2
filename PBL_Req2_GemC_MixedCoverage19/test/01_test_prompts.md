# GemC テスト用入力

## 複数行の特許CSVから選ぶ場合

```text
添付CSVから、公報番号と発明の名称だけを表形式で表示してください。
私が対象を指定するまで、特許分析、距離分類、候補発散は開始しないでください。
```

対象指定後：

```text
対象: JPxxxxxxxxxx
この1行だけを読み込み、GemCの発散前確認票まで進めてください。
候補発散はまだ開始しないでください。
```

## 公報番号を最初から指定する場合

```text
添付CSVの公報番号JPxxxxxxxxxxを対象に、要求機能②を開始してください。
対象行だけを読み込み、特許を分析し、GemCの発散前確認票までを表形式で提示してください。
この時点では候補発散を開始しないでください。
```

## PDFまたはCapability Cardを1件入力する場合

```text
添付した特許を対象に要求機能②を開始してください。
まず特許を分析し、GemCの発散前確認票までを提示してください。
19産業を一つも削除せず、near 6、adjacent 12、far 30の探索密度を表示してください。
この時点では候補発散を開始しないでください。
```

## 修正例

```text
修正:
- Situation B「漁業」はfarではなくadjacentとしてください。理由は〇〇です。
- Situation E「製造業」はnearとしてください。
修正後の候補総数を再計算し、確認票を再提示してください。まだ発散は開始しないでください。
```
