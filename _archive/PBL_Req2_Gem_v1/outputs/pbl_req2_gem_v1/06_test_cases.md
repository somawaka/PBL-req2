# OTB BtoB Meaning Explorer テスト入力 v1.0

いずれも三菱電機OTB公式ページで技術概要を確認できるシーズである。既存用途は新規候補として数えず、入力事実と転用仮説を分離する。

## TC01｜想定用途に近いもの：電磁指紋による真贋判定

狙い：既存の電子機器真贋・個体識別に引きずられず、近接候補の質とfar quotaを同時に確認する。

出典：https://www.mitsubishielectric.co.jp/corporate/chiteki/otb/list/094/index.html

### Gemへ貼る入力

```text
mode: quick
exploration_profile: balanced

OTBシーズ名：「電磁指紋®」による真贋判定技術
関連特許：特許第7154444号、特許第7607848号ほか

技術事実：
- 電子機器の製造ばらつきに由来する、複製や人為的再現が困難な電磁的特性を個体識別に使う。
- 事前登録した電磁的特性と判定対象を比較照合する。
- USB、LAN等の汎用コネクタから測定でき、特殊コネクタは専用治具で測定できる。
- 特別な識別回路の追加を要しない。
- OTB掲載の既存活用イメージは、電子機器メーカー、ECサイト、中古品取扱い業者の模倣品対策。

要件：
- 既存活用イメージの言い換えは新規候補へ数えない。
- FACT / INFERENCE / ASSUMPTIONを分ける。
- far候補では漁業または一次産業を少なくとも1枝含める。
```

期待確認：quick 12件、near 3 / adjacent 3 / far 4 / frontier 2。電子機器以外では「対象物から電磁特性を安定取得できるか」がASSUMPTIONとして残ること。

## TC02｜他産業へ転用可能そうなもの：空間操作インターフェース

狙い：医療・食品工場・クリーンルームという既存用途から、衛生以外の意味（機密、権限、技能、異常時等）へ転用できるか確認する。

出典：https://www.mitsubishielectric.co.jp/corporate/chiteki/otb/list/087/index.html

### Gemへ貼る入力

```text
mode: standard
exploration_profile: balanced

OTBシーズ名：空間操作インターフェース技術
関連特許：特許第6428665号、特許第6493240号、特許第6638450号ほか

技術事実：
- 上下に分割した操作空間ごとにジェスチャを切り替え、ポインタ移動、クリック、ドラッグ&ドロップ等を非接触で行う。
- 空中ガイドを立体表示し、操作可能な境界とフィードバックを知覚させる。
- 既存PCに近い複雑な操作を非接触で行える。
- OTB掲載の既存活用イメージは医療現場、食品工場、クリーンルーム等の衛生配慮環境。

要件：
- 医療・食品工場・クリーンルームの衛生用途はexisting_use_restatementとして候補数外にする。
- 「触らない」だけでなく、操作権限、肩越し覗き見、技能支援、手袋・装備、緊急時を検討する。
- Company名は生成しない。
```

期待確認：24件。SituationごとにActorが変わり、固定の「利用者」だけにならないこと。Meaning Lensは少なくとも8種類。

## TC03｜遠い文脈の発見：モノリス構造を利用した高信頼性接着

狙い：自動車・電子機器の部品接着という近接用途から、極限環境、修理・再利用、責任分界、地域インフラ等の遠距離意味を発見できるか確認する。

出典：https://www.mitsubishielectric.co.jp/corporate/chiteki/otb/list/091/index.html

### Gemへ貼る入力

```text
mode: standard
exploration_profile: far_emphasis

OTBシーズ名：モノリス構造を利用した高信頼性接着技術
関連特許：特許第7403726号、特許第7499994号ほか

技術事実：
- 共連続性の多孔質エポキシ樹脂を薄膜シート化し、任意の接着剤を含浸させて接着層として使う。
- 硬質で脆い接着剤の靱性を改善し、温度サイクル耐性を高め得る。
- 熱膨張率の異なる異種部材の高信頼接着に活用可能性がある。
- シートを挟んで硬化でき、接着剤厚み管理を簡便化できる。
- 細孔径、伸び率、弾性率、強度、導電性等を調整できる可能性がある。
- OTB掲載の既存活用イメージは、自動車エンジンルーム、電装部品、電子機器、ディスプレイの高温環境下接着。

要件：
- near 2 / adjacent 2 / far 5 / frontier 3で探索する。
- 既存用途の言い換えを候補数へ含めない。
- 極限環境、循環経済、災害レジリエンスのうち2つ以上を含める。
- 材料適合性や認証が不明なら、候補を削除せずReq③ unknownsへ送る。
```

期待確認：24件。単なる「強く接着できる」の用途列挙でなく、修理可能性、保守責任、長寿命化、現場判断、設備継続などの意味変化が出ること。
